## Setup (einmalig)

1. Auf [github.com](https://github.com) ein neues **öffentliches** Repository anlegen, z. B. `fi-lernspiele`.
2. Die Datei `index.html` aus diesem Ordner in das Repo hochladen (per GitHub Desktop committen + pushen, oder direkt im Browser über "Add file → Upload files").
3. Im Repo: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save.
4. Nach ca. 1–2 Minuten ist die Seite erreichbar unter `https://<dein-github-username>.github.io/fi-lernspiele/`.
5. Den Link oben in dieser README sowie in eurer Klassengruppe aktualisieren/teilen.

## Updates

Wenn im Vault ein neues Quiz-Paket dazukommt, einfach die aktualisierte `index.html` erneut ins Repo hochladen (überschreiben) und committen — GitHub Pages baut automatisch neu.
